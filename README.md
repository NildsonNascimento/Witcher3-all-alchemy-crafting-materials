# Alchemy & Crafting Supplies

A mod for **The Witcher 3: Wild Hunt 1.32(Classic)** that adds all Alchemy Ingredients and Crafting Materials to your inventory.


## Features

- Adds all Alchemy Ingredients.
- Adds all Crafting Materials.
- Adds items directly to your inventory using a keyboard shortcut.
- Includes an optional shortcut to add Crowns.

## Installation

1. Download the latest `.zip` file from [Releases](../../releases).
2. Extract the ZIP file.
3. Copy the `modAlchemyCraftingMaterials` folder into your The Witcher 3 `Mods` directory.

   ```text
   The Witcher 3/
   └── Mods/
       └── modAlchemyCraftingMaterials/
   ```

4. Open `input.settings`, located in:

   ```text
   Documents/The Witcher 3/
   ```

5. Find the `[Exploration]` section and add the following lines:

   ```ini
   [Exploration]
   IK_F4=(Action=ItemsWitcher)
   IK_F3=(Action=GiveMoney)
   ```

   

6. Save the file and launch the game.

## Controls

| Key | Action |
|---|---|
| `F4` | Adds all Alchemy Ingredients and Crafting Materials to your inventory. |
| `F3` | Adds 20,000 Crowns to your inventory. |

## Compatibility

Made for **The Witcher 3: Wild Hunt 1.32(Classic)**.
